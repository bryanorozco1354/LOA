FREE DEPLOYMENT
1. Create a free GitHub account.
2. Create a PUBLIC repository named door-tracker.
3. Upload index.html, manifest.webmanifest, icon.svg, and sw.js to the repository root.
4. Open repository Settings > Pages > Build and deployment > Deploy from a branch.
5. Select main and /(root), then Save.
6. Your site will appear at https://YOUR-USERNAME.github.io/door-tracker/ after publishing.
7. Open on iPhone Safari > Share > Add to Home Screen.

Each coworker has their own local data. Use Backup Data regularly. No customer personal information should be entered.
